Where the links come from

The point of these maps is that nothing in them is a guess. Each edge is extracted from the SUAVE source by parsing it:

LinkExtracted fromCount
containsthe package tree on disk872
inheritsclass bases, resolved through each defining module's own imports272
importsintra-SUAVE import statements2,036
useswhich components each energy network is assembled from134

Name resolution is scoped rather than global, which matters more than it sounds: SUAVE defines Fidelity_Zero four times — in Aerodynamics, Stability, Noise and Weights — and AVL, Costs and several mission segments are duplicated too. Matching base classes by bare name would merge them into one node and invent edges that do not exist, so every name is resolved through the import table of the module that uses it.

Reading them

  • Drag to rotate, wheel to zoom, hover to isolate a node with its links.
  • Click to pin a node and read its detail — module path, bases, subclasses, imports, and for a network its Mach envelope, engine counts and component chain.
  • Imports are off by default in the catalog view; 2,036 arcs at once is a hairball.
  • Every view has a table fallback, and both light and dark are designed rather than inverted.
